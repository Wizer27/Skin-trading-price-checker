# skinwatch

Утилита для Steam Community Market: сканирует цены и выводит **10 скинов, которые
продаются заметно дешевле, чем уходили за последние сутки** — с учётом комиссии площадки.

* без зависимостей — только стандартная библиотека Python 3.8+;
* ничего не хранит: запустил → получил таблицу;
* консольный вывод или JSON для скриптов.

```
$ python3 -m skinwatch

Top 10 skins that dropped and look worth buying
fee 15% · 'usual' = median of what actually sold in the last 24h

#  Skin                                       Now, USD  Usual, USD    Drop  Profit  Margin  Vol/24h  Lots
─  ─────────────────────────────────────────  ────────  ──────────  ──────  ──────  ──────  ───────  ────
1  AK-47 | Redline (Field-Tested)                 6.00        9.50  -36.8%   +2.07  +34.6%      900   400
2  Glock-18 | Water Elemental (Minimal Wear)      3.11        4.05  -23.2%   +0.33  +10.7%      260  1204
```

## Как это работает

1. **Поиск.** `/market/search/render` отдаёт имя, самый дешёвый лот и число лотов.
   Steam режет страницу до 10 позиций, поэтому `--pages 20` — это 200 позиций и
   20 запросов. Сортировка по ликвидности: там, где падение можно реально отыграть.
2. **Отбор.** Остаются позиции в коридоре `--min-price … --max-price` и с числом
   лотов не ниже `--min-listings`; из них берутся первые `--check` штук.
3. **Медианы.** Для них дёргается `/market/priceoverview`: медиана реальных продаж
   за 24 часа и объём продаж.
4. **Оценка.**

   ```
   drop   = (медиана − текущая) / медиана × 100
   net    = медиана × (1 − комиссия 15%)     # сколько реально придёт на кошелёк
   profit = net − текущая
   score  = margin% × confidence             # confidence растёт от объёма продаж
   ```

Комиссия 15 % — главный фильтр: чтобы перепродажа вышла в плюс, покупать надо дешевле
85 % медианы, то есть падение должно быть заметно больше 15 %. Если цель не перепродать,
а купить себе — запускай с `--fee 0 --min-margin 0`.

## Запуск

```bash
python3 -m skinwatch                         # CS2, USD, топ-10
python3 -m skinwatch --currency 5            # цены в рублях
python3 -m skinwatch --app 730,570           # CS2 + Dota 2
python3 -m skinwatch --pages 40 --check 60 --min-drop 12
python3 -m skinwatch --query "AK-47" --min-price 5
python3 -m skinwatch --fee 0 --min-margin 0  # просто «что сейчас дёшево»
python3 -m skinwatch --json > drops.json
python3 -m skinwatch apps                    # id игр и валют
```

### Флаги

| Флаг | Что делает | По умолчанию |
|---|---|---|
| `--app` | id игры или список через запятую | `730` (CS2) |
| `--currency` | валюта Steam: 1=USD, 3=EUR, 5=RUB, 18=UAH, 37=KZT | `1` |
| `--pages` | страниц поиска, по 10 позиций каждая | `20` |
| `--sort` | порядок обхода: `quantity`, `price`, `default`, `name` | `quantity` |
| `--query` | искать только по имени, например `"AK-47"` | — |
| `--check` | сколько позиций проверить через priceoverview | `40` |
| `--top` | сколько скинов вывести | `10` |
| `--min-drop` | минимальное падение, % | `8` |
| `--min-margin` | минимальная чистая прибыль после комиссии, % | `3` |
| `--min-volume` | минимум продаж за сутки | `5` |
| `--min-listings` | минимум лотов в продаже | `10` |
| `--min-price` / `--max-price` | коридор цен | `0.5` / `500` |
| `--fee` | комиссия долей (0.15 = 15 %) | по игре |
| `--delay` | пауза между запросами, с | `4` |
| `--transport` | `auto` / `curl` / `urllib` | `auto` |
| `--links` | печатать ссылки на маркет | — |
| `--json` | машинный вывод | — |

Скан по умолчанию — 60 запросов, примерно 4 минуты.

### Лимиты Steam

Steam пропускает около 20 запросов в минуту на все market-эндпоинты вместе, поэтому
пауза по умолчанию 4 секунды, а при 429 клиент сам ждёт с растущей паузой и прекращает
после трёх неудач подряд.

Две особенности их антибота, на которые напоролись при отладке:

* Steam режет часть TLS-отпечатков Python и отвечает 429 даже на первый запрос — поэтому
  запросы по умолчанию идут через `curl` (есть в macOS и почти любом Linux). Явно выбрать
  бэкенд: `--transport urllib` или `--transport curl`.
* `priceoverview` отдаёт 429 на «браузерный» `Accept-Language: en-US,en;q=0.9`, хотя на
  `en` и без этого заголовка отвечает 200. Клиент его не шлёт — не добавляйте обратно.

## Дисклеймер

Инструмент показывает статистику публичного маркета, а не инвестиционный совет.
Низкая цена бывает и по делу: скин может падать дальше, у предмета могут быть
торговые ограничения, а медиана продаж — не гарантия того, что его купят.
